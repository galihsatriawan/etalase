# Etalase Academy

A VitePress site that teaches the whole Etalase project, from zero to master.

```bash
cd learn
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in .vitepress/dist
```

To publish on GitHub Pages under `https://<user>.github.io/etalase/`, build with
`BASE=/etalase/ npm run build` and serve `.vitepress/dist`.
